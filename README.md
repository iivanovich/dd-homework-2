# Ночь в музее — карточка события

Одноколоночная карточка посещения события с программой и расчётом услуг.  
Объединяет JSON, HTML/CSS и DOM.

## Функционал
- Отображение данных события (заголовок, дата, место, описание).
- Кнопка «Показать программу» (раскрывает время сбора и начала).
- Форма выбора услуг (гид, аудиогид, каталог) с расчётом итоговой суммы.
- Вывод отчёта: количество услуг, общая стоимость, список выбранных позиций.
- Отображение JSON-строки отчёта.
- Обработка ошибок: повреждённый JSON, пустой выбор услуг.

## Стек
- HTML5, CSS3, JavaScript (ES6+)
- Без фреймворков, Flexbox и Grid

## Как запустить
1. Откройте `index.html` в браузере (без сервера).
2. Либо разверните на GitHub Pages / GitVerse Pages.

## Файлы
- `index.html` — разметка страницы.
- `style.css` — стили.
- `app.js` — логика (парсинг JSON, расчёт услуг, обработка событий).
